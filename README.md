## Set up

You will need Node.js and npm installed, the installer here (https://nodejs.org/en) installs both.

Run the following commands:

```npm install```

Downloads the dependencies listed in ```package.json```

```npm run dev```

Starts the app. The terminal will display a local URL, open it to view the app. You can keep the terminal running, changes you save in the code will automatically appear in the browser without needing to rerun the command.
